# Finding_Factorial
A simple Python backend script to calculate factorials. Just run it in your terminal, input a number, and let the loop do the math!



🚀 Fun Ways to Use It
The "Big Number" Challenge

Run the script and try entering a surprisingly large number (like 50 or 100) to see how fast factorial numbers grow. Watch your terminal fill up with digits in a split second!

The Edge-Case Tester

See how the script handles the boundaries:

Put in 0 or 1 to test the base cases.

Put in a negative number (like -5) to see how it catches errors with a friendly message instead of crashing.

CLI Math Assistant

Keep it running in your background terminal whenever you are doing quick math homework or probability calculations and need instant factorial values without opening a calculator app.
